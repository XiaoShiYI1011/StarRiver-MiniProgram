# 星河创作微信小程序

简体中文 · [English](README.en.md)

星河创作的微信小程序前端，基于 **UniApp、Vue 3 和 TypeScript**，提供产品介绍、账号绑定、作品概览、套餐与权益展示、订单查询及购买流程。

**星河创作**是一款面向长篇小说与剧本创作的 AI 辅助工具，围绕作品、章节、人物与世界观设定、故事记忆和写作方案组织创作过程。本项目是其微信端入口，方便用户查看账号、作品和服务信息。

> 本仓库公开小程序前端源码。小说与剧本创作请使用星河创作电脑端。内容生成、模型调用、数据存储、计费和支付校验由独立后端提供。

## 星河创作与本项目

星河创作的完整产品包含以下能力。

- **小说与剧本创作**。围绕作品开展内容生成、阅读、编辑和保存。
- **设定与故事记忆**。组织人物、世界观、重要事件和相关资料，为持续创作提供上下文。
- **写作方案**。管理写作方向和生成参数，适配不同创作阶段。
- **作品整理与导出**。整理已保存内容，供后续编辑、备份和使用。

## 快速开始

### 1. 准备开发环境

- Node.js 与 npm。
- HBuilderX，以及项目所需的 UniApp 编译器。
- HBuilderX 的 `compile-typescript` 和 `compile-dart-sass` 插件。
- 微信开发者工具。
- 自己的微信小程序 AppID。
- 用于业务联调的兼容后端。

首发编译使用 Node.js 22.20.0、npm 10.9.3 和 HBuilderX 自带的 UniApp Vue 3 编译器 5.24。

当前构建脚本依赖 HBuilderX 编译器。请先安装对应编译器和插件，再执行构建。

### 2. 安装依赖

下载或克隆本仓库，在项目根目录执行：

```powershell
npm ci
```

### 3. 配置后端地址

在项目根目录创建本地 `.env` 文件，可从 `.env.example` 开始。

```dotenv
VITE_API_BASE_URL=https://your-api.example.com
VITE_DEBUG_PANEL=false
```

将示例地址替换为自己的后端地址，并在微信公众平台配置相应的 request 合法域名。修改 `manifest.json` 和 `project.config.json` 中的小程序 AppID，使用自己的应用配置。

`VITE_` 变量会用于前端构建。AppSecret、模型密钥和支付密钥应由服务端管理。

### 4. 检查代码

```powershell
npm run type-check
npm run lint
```

### 5. 构建微信小程序

可以通过 HBuilderX 打开项目并运行到微信开发者工具，也可以配置安装路径后调用项目脚本。

```powershell
# 替换为本机实际安装路径
$env:HBUILDERX_HOME = 'D:\Apps\HBuilderX'

npm run build:mp-weixin
```

将生成的 `unpackage/prototype-check/mp-weixin` 目录导入微信开发者工具。首次业务联调可先验证接口连通性与登录流程。

### 6. 预览 H5 界面

```powershell
npm run build:h5
```

通过本地 HTTP 服务访问 `unpackage/prototype-check/h5`。H5 用于检查布局和样式，登录和支付请在微信环境下验证。

## 项目结构

```text
api/                 后端接口调用
components/          通用组件
composables/         共享状态与交互逻辑
config/              配置读取
content/             产品介绍与静态文案
layout/              页面容器与布局
pages/               首页、扫码购买等主包页面
packages/
  account/           账号、绑定、作品、订单与协议
  shop/              套餐与购买流程
scripts/             构建及代码检查脚本
services/auth/       微信登录与认证会话
static/              静态资源
styles/              公共样式
types/               接口与业务类型
utils/               请求、路由和通用工具
```

页面和组件通过 `api/` 中的接口模块访问业务数据。通用请求逻辑位于 `utils/request.ts`，后端基地址由 `config/api.ts` 读取。

## 前后端职责

| 小程序前端负责 | 后端负责 |
| --- | --- |
| 页面展示与用户交互 | 身份校验、权限判断与数据访问 |
| 获取微信登录凭据并发起认证请求 | 微信身份交换、账号绑定与会话管理 |
| 展示作品、套餐、报价和订单 | 保存业务数据、计算价格与管理订单 |
| 调起支付并展示处理状态 | 生成支付参数、校验结果与发放权益 |
| 展示错误和刷新数据 | 内容生成、模型调用与任务执行 |

本仓库提供前端实现。联调账号、订单和支付需要兼容后端，目前没有内置完整离线模拟服务。

## 常见问题

### 星河创作是什么？

星河创作是一款面向长篇小说与剧本创作的 AI 辅助工具，提供围绕作品、章节、设定、故事记忆和写作方案组织的创作功能。本仓库是它的微信小程序前端。

### 可以直接在这个小程序中写小说或剧本吗？

写作和章节编辑请在电脑端完成。小程序可用于查看产品介绍、账号、作品概览、套餐与订单等信息。

### 下载源码后能否独立运行完整服务？

可以配置开发环境、检查代码并构建前端。运行登录、作品数据、订单和支付需要连接兼容后端。完整创作服务由星河创作电脑端和后端提供。

### 能接入自己的后端吗？

可以按项目的请求、类型和认证约定进行适配。若接口结构不同，需要修改接口模块及相应业务逻辑。

### 小程序是否包含 AI 模型？

星河创作的模型调用与内容生成由后端处理，本仓库的业务范围是小程序前端。

### 源码公开是否代表星河创作服务免费？

源码使用范围由项目许可证决定。线上服务的使用条件、价格和权益由产品服务规则决定。

### GitHub 和 Gitee 的代码有什么区别？

两者是同一项目的官方镜像，发布内容保持一致。出现短暂同步延迟时，可通过提交记录核对版本。
